# Agent_TRAE · 电商工作台

国内抖音、微信小店 & 跨境 TikTok Shop 的电商运营协作仓库。

## 目录结构

```
/workspace
├── _templates/              # 跨平台复用模板
│   ├── 选品分析模板/
│   ├── 竞品分析模板/
│   ├── 利润测算模板/
│   └── 爆款拆解模板/
│
├── _assets/                 # 公共资源
│   ├── 素材库/
│   └── 工具脚本/
│
├── 国内/
│   ├── 抖音/                # 国内抖音平台
│   │   ├── 选品/
│   │   ├── 竞品分析/
│   │   ├── 内容素材/{短视频脚本, 直播话术}/
│   │   ├── 投放策略/
│   │   ├── 数据复盘/
│   │   └── 月度方案/
│   └── 微信小店/            # 国内微信小店平台（模块同上）
│
└── 跨境/
    └── TikTokShop/          # 跨境 TikTok Shop（模块同上）
```

## 平台业务模块说明

每个平台统一六个子模块：

| 模块 | 用途 |
|------|------|
| **选品** | 市场机会判断、爆品方向、选品决策 |
| **竞品分析** | 竞品拆解、卖点提炼、差异化策略 |
| **内容素材** | 短视频脚本、直播话术、图文素材 |
| **投放策略** | 广告投放方案、达人合作规划 |
| **数据复盘** | 运营数据、销售数据、ROI 分析 |
| **月度方案** | 月度运营计划、活动策划 |

## 快速开始

- 用蝉妈妈做国内电商分析 → 直接进 `国内/抖音/` 对应模块
- 用跨境选品工具做 TikTok Shop → 进 `跨境/TikTokShop/选品/`
- 需要模板 → 去 `_templates/` 拷贝复用
- 需要调整目录 → 告诉我，随时可以改
